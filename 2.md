# 🧩 Problem Statement (NetworkPolicy - Pod Label Access)

<details>
<summary>Click to expand the problem statement</summary>

A Kubernetes cluster is already configured. You must connect to the **correct context** before attempting the task.

**Context:**
You need to restrict a Pod so it can only communicate with two specific Pods, and no others.

**Task:**

Update the Pod `app-connector` in the namespace `netpol-lab` so that it can **only communicate** with the Pods `frontend` and `datastore` using the **existing NetworkPolicies**.

> **Do NOT create, modify, or delete any NetworkPolicies**.

</details>

### 📥 Script : setup_q02_problem_scenario.sh

Run this **before you start practicing** this problem.
Re-run anytime you want to practice again after fixing.

```bash
#!/bin/bash
# ============================================================
# CKAD Practice | Q02: NetworkPolicy - Pod Label Access
# setup_q02_problem_scenario.sh
# Deploys 4 pods + 4 NetworkPolicies, app-connector unlabeled
# Run on: controlplane node
# ============================================================

set -euo pipefail

NAMESPACE="netpol-lab"

echo ""
echo "==========================================="
echo " CKAD Q02 — Setting up NetworkPolicy scenario..."
echo "==========================================="
echo ""

# ── Step 0: Full reset — delete namespace if it exists ────────
# Guarantees a clean problem state every time, regardless of
# any labels/patches the user applied while solving previously.
echo "[0/4] Clearing any previous scenario state..."
kubectl delete namespace "$NAMESPACE" --ignore-not-found
echo "  Waiting for namespace deletion to complete..."
while kubectl get namespace "$NAMESPACE" &>/dev/null; do
  sleep 2
done
echo "  Cleared."

# ── Step 1: Create the namespace ───────────────────────────────
echo "[1/4] Creating namespace '$NAMESPACE'..."
kubectl create namespace "$NAMESPACE"
echo "  Namespace created."

# ── Step 2: Create the four Pods ───────────────────────────────
echo "[2/4] Creating Pods (frontend, datastore, app-connector, extra-pod)..."

kubectl apply -f - <<EOF
apiVersion: v1
kind: Pod
metadata:
  name: frontend
  namespace: $NAMESPACE
  labels:
    app: frontend
    item: netpol-lab
spec:
  containers:
  - name: frontend
    image: devopstechtales/ckad-exam-questions:netpol-fe
---
apiVersion: v1
kind: Pod
metadata:
  name: datastore
  namespace: $NAMESPACE
  labels:
    app: datastore
    item: netpol-lab
spec:
  containers:
  - name: datastore
    image: devopstechtales/ckad-exam-questions:netpol-datastore
---
apiVersion: v1
kind: Pod
metadata:
  name: app-connector
  namespace: $NAMESPACE
  labels:
    app: app-connector
    item: netpol-lab
spec:
  containers:
  - name: app-connector
    image: devopstechtales/ckad-exam-questions:netpol-app-connector
---
apiVersion: v1
kind: Pod
metadata:
  name: extra-pod
  namespace: $NAMESPACE
  labels:
    app: extra-pod
    item: netpol-lab
spec:
  containers:
  - name: extra-pod
    image: devopstechtales/ckad-exam-questions:netpol-extra-pod
EOF

echo "  Waiting for all pods to be Ready..."
kubectl wait --for=condition=ready pod --all -n "$NAMESPACE" --timeout=120s
echo "  All pods Ready."

# ── Step 3: Create the NetworkPolicies ─────────────────────────
echo "[3/4] Creating NetworkPolicies..."

kubectl apply -f - <<EOF
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: access-frontend
  namespace: $NAMESPACE
spec:
  podSelector:
    matchLabels:
      app: frontend
  policyTypes:
  - Ingress
  ingress:
  - from:
    - podSelector:
        matchLabels:
          frontend-access: "true"
---
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: access-datastore
  namespace: $NAMESPACE
spec:
  podSelector:
    matchLabels:
      app: datastore
  policyTypes:
  - Ingress
  ingress:
  - from:
    - podSelector:
        matchLabels:
          datastore-access: "true"
---
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: all-access
  namespace: $NAMESPACE
spec:
  podSelector:
    matchLabels:
      all-access: "true"
  policyTypes:
  - Ingress
  - Egress
  ingress:
  - {}
  egress:
  - {}
---
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: default-deny
  namespace: $NAMESPACE
spec:
  podSelector: {}
  policyTypes:
  - Ingress
EOF

echo "  NetworkPolicies created."

# ── Step 4: Verify ──────────────────────────────────────────────
echo "[4/4] Verifying resources..."
kubectl get pods -n "$NAMESPACE" --show-labels
kubectl get networkpolicy -n "$NAMESPACE"

echo ""
echo "✅ Q02 scenario is ready!"
echo ""
echo "   3 pods to consider: frontend, datastore, app-connector"
echo "   app-connector currently has NO access labels."
echo "   Now go fix it! 💪"
echo ""
```

# ✅ Solution

<details>
<summary>Click to expand the solution</summary>

---

### Step 1: List existing NetworkPolicies

```bash
kubectl get networkpolicy -n netpol-lab
```

Output:
```
NAME               POD-SELECTOR
access-datastore   app=datastore
access-frontend    app=frontend
all-access         all-access=true
default-deny       <none>
```

---

### Step 2: Describe NetworkPolicies to find required labels

**Check access-frontend:**

```bash
kubectl describe networkpolicy access-frontend -n netpol-lab
```

Key output:
```
PodSelector:  app=frontend
Ingress - From PodSelector: frontend-access=true
```

> So any pod that wants to talk to `frontend` must have label `frontend-access=true`

---

**Check access-datastore:**

```bash
kubectl describe networkpolicy access-datastore -n netpol-lab
```

Key output:
```
PodSelector:  app=datastore
Ingress - From PodSelector: datastore-access=true
```

> So any pod that wants to talk to `datastore` must have label `datastore-access=true`

---

### Step 3: Add required labels to app-connector

```bash
kubectl label pod app-connector -n netpol-lab frontend-access=true
kubectl label pod app-connector -n netpol-lab datastore-access=true
```

---

### Step 4: Verify labels applied

```bash
kubectl get pod app-connector -n netpol-lab --show-labels
```

Expected output:
```
NAME            LABELS
app-connector   app=app-connector,item=netpol-lab,frontend-access=true,datastore-access=true
```

✅ `app-connector` can now communicate with `frontend`
✅ `app-connector` can now communicate with `datastore`
✅ No new NetworkPolicies were created or modified
